# 认知成果历史检索开发记录

2026-11-20。此次仅修改源代码并做隔离验证，未操作正在使用的工作台，未调用模型。

## 实际问题

历史搜索原先只覆盖问题、判断、资料标题和缺口。工作地图里的分类边界、迁移条件与未知，以及修订理由、逐项对照和行动建议，虽然已经保存在研究结果中，却不能用于查找原研究。只有记得原问题或判断措辞时才能找到部分成果。

## 改动

- 历史搜索复用已有地图内容读取，涵盖分组、工作/能力关系、关系比较、范围与未知。
- 认识修订可按旧判断、新表述、修订理由和逐项对照内容查找；行动建议可按任务、交付物、检查方式、前提与待问问题查找。
- 界面区分工作地图、认识修订和行动建议匹配，保留历史分析仍需核对、建议不表示已执行的含义。搜索仍只定位原研究，不把历史内容作为新的原文证据或自动采纳为当前结论。
- 搜索使用已有同形部首比较，返回摘录仍保留原字形。继续沿用原有分页、命名空间、遗忘记录及已遗忘项目排除逻辑，不读取模型检查点上下文。
