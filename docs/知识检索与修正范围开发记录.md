# 知识检索与修正范围开发记录

2026-11-20，继续接通跨会话知识与后续认知修正。

## 已复现的缺口

普通记忆召回未将本轮岗位范围传给修正提醒读取，统一检索也未将所选归档范围传入召回，因此可能带入依赖未选资料的新判断。领域关系走另一条范围过滤路径，却按后续整轮读取的所有资料判断，可能隐藏仅依据本轮资料的有效修正。统一检索页面虽然收到修正提醒，原来没有展示。

另外，检索的长度预算只计算知识文字及其原文，未计算后续修正和逐项对照；较长修正可能绕过既有内容上限。

## 本批行为

- 普通记忆、统一检索和领域关系采用同一修正读取规则。项目归属、遗忘、拒绝核对与时间限制继续生效。
- 一条修正的范围取自身引用及所指新判断的引用，不取后续整轮顺便读取的无关资料。
- 修正依赖本轮未选资料时，保留“有后续研究需补充资料核对”的有限提醒；具体理由、新判断、逐项内容和引用不带入。既不将范围外分析当成本轮证据，也不因缩小范围使旧知识看似没有后续疑问。
- 统一检索显示后续修正、原判断与回查入口。提醒中的文字计入既有内容上限；放不下时省略整条并说明本次召回中有未展开认识及修正，不截短原记录，也不自动撤回已采纳知识。

隔离资料复现了范围外新判断进入召回的问题，相关修正范围、选择归档、领域关系、展示长度与页面渲染检查通过。没有新增真实模型调用、改写历史研究、改动原始资料或更新运行实例。当前证据证明检索及提醒的行为，不代表后续认知意见已经得到独立语义确认；完整GOAL继续进行。
