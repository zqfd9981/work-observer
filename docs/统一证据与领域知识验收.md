# 统一证据与领域知识

## 0.6：关系知识遵守上游修订

已补上源研究资格：人审采纳的关系仍保留`source_run_id`回链。其源研究使用的偏好/纠正已修订、撤回、冲突、过期，或更早研究/关系已失效时，关系会显示需要复核且不作为当前Agent线索；不能仅凭本条`active`和JD仍存在绕过上游变化。新候选也不能采纳缺失或未完成的源运行。

报告审计新增`stale_dependencies/dependency_issues`；同一有界审计检查源运行、引用版本、关系定义、人类审核拒绝及继承范围，不通过召回和报告相互递归。最多96节点、12层，循环或无法核验保守停止复用。知识状态及原文不被静默改写，历史认识仍可查看；当前有效性与原人审采纳状态分别展示。Agent辅助评价不等于人类审核，语义支持仍须核对。具体真实缺陷复现、准确续接案例和边界见[派生资格审计](记忆修订与派生资格审计.md)。

还修复了等待资料的口径遗漏：原资料指纹只看原文、记忆与程序方法，新增并采纳相关领域定义后仍报“没有新资料”。现在与研究工具共用有界领域/关系检索，将相关、有效、范围覆盖的定义版本、关系审核时间与源运行ID纳入口径指纹。每次最多10个词面线索、6个定义和10条关系；待审、无关、其他岗位或其他项目的关系不触发当前范围的新材料。4项专项验证口径采纳后可显式新轮、候选/无关口径不触发、岗位范围和项目范围不越界。词面匹配仍有遗漏边界，不代表完整语义召回。

## 可操作流程

工作台“领域与证据”入口使用与 API 相同的服务：

1. 搜索岗位原文与已归档公开材料。岗位使用当前筛选范围，也可限定岗位页勾选项；历史截止为北京时间。没有命中仍是未知，不能推断某项要求不存在。
2. 逐条核对片段，选择支持证据或反例。来源时间、正文版本与精确字符位置保留；原始文件和提取正文都重新核对 SHA。公开业务背景不能单独证明某岗位任务或资格。
3. 创建领域定义，写明包括、排除和未知的边界。定义先成为候选，填写审核说明后才能采纳。修订、合并、拆分均保留定义版本和关联；采纳新定义不会静默把旧岗位或关系改成新口径。
4. 从任务、交付物、责任、能力、工具和业务背景建立有方向的关系，明确支持和反例。关系先成为候选；存在冲突时须先明确拒绝或撤回旧认识，不能自动覆盖。反例保留独立范围，不会计作正例岗位。
5. 浏览领域集合，查看全范围的归入、未知和不归入数量。计数发生在分页前。明确的单岗人工纠正优先；新纠正绑定所采用的领域定义版本，新版本扩大边界后不会自动沿用旧纠正。

公开材料默认每个 URL 只采用最新已归档版本。显式资料 ID 可重放旧版本，截止时间不包含后来取得的材料。派生知识只作为已采纳认识返回，仍回链原文，不生成第二份独立证据。独立报告、研究摘要和通知不加入原文语料。

## Agent 接线与边界

研究工具 `search_archived_sources` 在原候选范围内查询统一资料。首轮冻结每 URL 最新公开材料的 ID、完整 URL 数、截断标志、研究截止时间和别名策略；最多 500 个公开 URL。恢复时仍使用原范围、原时间和原策略，后导入岗位、岗位新版本、官网新版本和新启用别名不会混入。

统一查询复用原筛选条件的三值语义，不会把薪资或地点未知的候选重新计作明确匹配。最多返回 20 条原文片段，原文和派生认识的文本总量不超过 7,000 字符；每份来源先取代表片段，再补充同源片段，避免长官网正文挤掉短 JD。

`browse_domain_knowledge` 使研究 Agent 能主动查阅已审核领域定义和工作关系。每项研究累计最多采用 6 个定义与 10 条关系；只返回有效记录，正例和反例引用均须处于本轮固定岗位、启动时冻结的公开材料及允许项目范围，审核时间不得晚于研究启动。它只给出派生表述、适用范围和原文定位信息，不把引用原文放入已读证据池。Agent 仍须通过 `read_job` 或 `search_archived_sources` 重读原文，才能提交有引用的判断；复制关系中的来源 ID 直接提交会被拒绝。

研究结果的 `knowledge_used` 只保存采用记录的类别、编号、版本/审核时间与状态；关系的上游研究编号加入 `continued_from`。这让遗忘闭包能定位经领域关系间接续接的后续研究，不将关系当作独立来源来切断回链。暂停恢复、每次模型调用前后及提交前都会重新校验已采用知识；定义换版、关系撤回、冲突或来源变化会阻止旧上下文继续，标记 `stale_knowledge`，要求重新研究。历史报告的审计也会显示这一状态。该工具只读，不能激活、合并或修改领域关系。

只有公开材料时也可研究发布者业务。纯公开原文可支持业务背景的直接判断；非业务背景的直接岗位判断至少需要候选 JD 引用。推断必须标为推断，仍需后续核对。这项护栏检查来源类别与引用合同，不能自动证明一句 JD 在语义上充分支持判断。

离线模式整理有界岗位和公开原文包，不调用模型，不宣称完成研究。来源完整性失败会排除相应引用。已采纳知识依赖的来源变化后停止默认召回；关系依赖来源变化、定义换版或待审冲突后显示需要重新核对。遗忘闭包可按上游研究编号清除派生关系表述及引用，原 JD 和公开原文保留。

## 仍未验证或未完成

领域和关系目前需要明确的创建与人审，不会自行把开放研究结论升级为权威领域定义。语义冲突发现、规模化知识维护、独立人工标注的跨企业关系质量、长期领域演化和真实趋势尚未验证。现有固定领域画像枚举保留，新审核定义与集合入口已独立可用，但画像模型的开放领域发现仍需更充分的业务评估。历史集合只用截止前且目前仍有效的分类依据，不宣称完整重建任意过去时刻的人工审核状态。
