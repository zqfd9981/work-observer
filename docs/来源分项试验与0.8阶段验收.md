# 0.8 来源分项试验与阶段验收

2026-11-19，单用户本地Alpha。Goal继续；没有恢复招聘来源、推送或对外发布。本阶段保留一次未能证明整体收益的真实方法试验，不把执行完成、工程检查或Agent评分写成人类验收。

## 为什么试验

0.7仍出现“个人编码份额/独立程度未知”扩大为“岗位没有明确开发职责”。已有提示已经提醒未知不能抹去明确建设任务，因此本轮增加可核对的来源分项结构，并保留v5标准方法和原摘要作为默认。试验不是另加产品Agent或隐藏审核调用。

候选先读取冻结JD，以原文分句按岗位分别登记建设任务、产出、个人编码份额、独立端到端程度、上线权限、平台运行角色、人工控制、资格、工具和业务方向。明示、明示否定、未披露与仍不清楚分开；finding不另造一套自由事实，只保存精确分句及维度。岗位建设和平台中的CEO/Leader/执行Agent角色不可自动等同；未知不能替换同维度明示记录。

分句保留Unicode字符绝对位置、来源证据、同一版本及已读上级标题/方向；标题仅启发式定位，不推断职责。合并重叠阅读范围但不重复计数，缺口与展示截断分别标记。只有实际返回模型、同一冻结正文已读全且分句全展示，才允许登记该维度“未披露”；摘要和内部pool全量加载均不能冒充阅读全文。长正文可用有界read_source_window补齐。

每条候选claim绑定活动finding和对应来源；跨岗比较逐侧同维度并用synthesis。未知单独展示，不能作为自由肯定/排除判断的事实依据。登记错误可在原预算内修正，整个无效批次不改变记录；修订用新ID/supersedes/理由保留历史。所有调用、修正和token计入原预算，不能为满足分项结构无限续跑。

这些检查只证明定位与结构，不证明任意自由综合与原文同义。模型仍可能错分维度、把正面分句标成否定、漏动作或误解角色；同维度正反记录可能对应不同对象，不能按状态名自动判矛盾。来源存在也不能证明“未披露”。这仍须逐项语义核对。

## 真实开发比较

独立开发分工先锁3题、每题6项完成条件，范围1/2/2岗，覆盖0.7双岗组以外其余5份既有正文；作者只写任务与条件，没有理想答案或标签。正文此前在开发中暴露，任务由Agent辅助编写，不是独立人类任务、新holdout或未见企业泛化。

先只读backup正式库到隔离目录，再锁问题、来源SHA、两臂实际方法、策略、空个人/项目上下文、预算与顺序；一题标准先、一题候选先、第三题标准先。两臂均固定本地JD、禁公开和候选提案。每次8调用/240秒，整组最多48调用/1600秒，失败与未完仍占原题槽位。

| 固定开发任务 | 标准方法执行 | 来源分项候选执行 | Agent辅助业务核对 |
| --- | --- | --- | --- |
| 多方向座舱云端岗位的专攻/资格/权限 | 4次，完成，20判断 | 5次，完成，14判断/19分项 | 双方6项criteria满足；标准仍漏question要求的资格核实问题，候选本题六维满足 |
| 广告平台与企业知识库的交付/协作/评估 | 5次，完成，19判断 | 8次，未完，22分项 | 标准4/6criteria满足，存在控制角色/资格问题；候选无终稿，不能拿分项代替已回答 |
| 转岗初筛的资格强度/优先/例外 | 5次，完成，18判断 | 8次，未完，24分项 | 标准4/6criteria满足，仍有来源层及资格问题；候选无终稿 |

实际35次模型调用，总296.625秒；标准14调用/89.374秒/73,203token，候选21调用/206.336秒/268,309token，费用未知。无公开搜索、招聘、认证或恢复暂停请求。候选两份未完保留原history、拒绝反馈和分项，没有加额度、换结果、删题或将同题重跑包装为新验收。

两份未完含分项登记/引用关联修正、未知finding用于自由claim、跨维度对比等拒绝。其中unknown_cannot_support_exclusionary_claim是结构规则的错误标签，不能据此断言每个被拒文本都真在否认职责；合法的“某个人分工未知”自由表述也可能因未放到独立未知区而被拒。这是方法的可用性/预算代价，不将全部拒绝算作语义纠错收益。

6包随机不透明编号匿名核对，包括两包空claims和65分项。审核者未读方法映射/执行日志，但写作风格、分项结构与其任务作者经历可能造成识别；声明不能证明盲法、身份或独立人审。71条终稿claims的辅助意见为65支持、2不支持、4未知，资格分类错误3条；36项criteria为20满足、16遗漏。不能用完成包的14/14或65/71计算总体正确率、掩盖两份未完。

封评配对为insufficient：标准0题、候选1题满足整体业务条件，仅是一题局部Agent辅助正反馈；候选两题未完成且token更多，缺独立人审、新预留样本与复验。当前空上下文和策略摘要两侧一致，未检出这两类混杂，但不是随机化严格单变量因果证据，更不能推广到其他公司或市场。没有替换默认方法、激活知识或启用候选。原criteria不完全覆盖question的一处遗漏也保留，未事后修改criteria追认通过。

私有证据：data/phase08-task-author、data/phase08-development/20261119-8543b9fd。包含预注册、冻结来源、6权威运行、原匿名包、原评语、封评、实际用量和失败诊断。试验后仅格式化一处代码缩进；运行时4份实现及摘要另存implementation，AST等价凭据披露源码哈希因此变化，未重写旧协议或将旧结果重新绑定当前摘要。发布候选仍是待验证试验，不能声称已通过真实验收。

## 可操作入口与恢复

研究工作台默认“现有研究方法”；主动选“先分项核对原文（试验）”才用候选，公开补查取消并禁用。页面说明登记/修正占原额度、可能无法完成、尚未证明整体收益。离线仍只是证据包。CLI显式参数：

```powershell
uv run --locked work-observer research --question "比较所选岗位明确任务与未知分工" --job-id 岗位ID --approach source_first --max-calls 8 --timeout 240 --db data/isolated/app.db
```

POST /api/research的approach枚举standard/source_first默认standard；旧sealed input缺字段只解释为standard，不回写旧记录。权威input/result/checkpoint保留选择；恢复从原输入取值，不能改方法/范围/预算，候选实现摘要变化要求新run。项目、日常流程和画像当前继续标准方法，未开放候选选择，不把直接研究试验说成已改善整条日常流程。现有104个API路径不增加，仅合同显式支持可选方法。

研究结果、已存报告、Markdown、普通质量审核和匿名方法审核均展示活动分项及未知，保留修订摘要；审核页不隐藏分项只展示被挑出的终稿，匿名页不显示arm/方法摘要/旧评分。自由模型分析仍须审核，不能覆盖原文动作。浏览器合成验收完成选择→禁公开→实际工具替身分项→精确字符高亮→保存/重开报告→保存Agent待审→查看完整匿名分项。390px无整页横溢出，视口已恢复、控制台无警告/错误。所有浏览器样例标明合成，不是真实业务验收。
