# 有限本地检索试用与回退

2026-11-19，0.6增量。将冻结真实资料上的配对评测接到旁路比较、明确人审、局部试用、质量反馈与回退。它不是全局策略自动启用，也不证明研究答案的语义普遍正确。

## 已实现的门槛与范围

1. 固定语料、题集、基线/候选别名、候选锁、单次预留验收记录与结果摘要。新评测另固定检索实现摘要；软件或配置变化不能沿用旧授权继续试用。
2. 新题集必须明确声明 `label_origin=human`、标签独立于候选调参，并在候选和预留验收前锁定。默认、旧套件与Agent草案没有此声明，仍为证据不足。预留题只在服务内部核对既有结果，不作为Agent工具或页面内容返回。
3. 重新核对冻结结果的逐题检索输出、引用位置、来源SHA、预算和聚合指标，不能只信结果文件中的一个accepted字符串。固定门槛不能由API改动。
4. 先对当前局部资料做旁路比较，核对开发查询的原文片段、召回与精确率。只允许冻结开发集中已验证的**精确查询组合**，不能把新词或新范围偷偷变成已验收。
5. 只有独立人工标签声明、预留验收、局部旁路均满足后，用户再次明确人审才能授权。Agent协助意见不能授权候选。
6. 最多20个完整正文岗位、20次候选检索、自建立旁路起最多24小时。使用当前样本指纹、软件、配置、文件完整性和上游资格护栏。默认检索与全局采集权限始终保持原设置。

这里的“人类”“独立标签”来自已认证单用户操作人的明确声明。程序核对声明、版本与文件一致性，**不证明实际身份、标注真实性或独立性**；哈希也不是对恶意本机管理员的认证。当前没有收到真实用户人审，不运行或宣称任何真实accepted激活。

## 页面流程

“有限检索试用”页面先选择固定评测包、开发查询与局部范围，建立旁路比较。可直接查看基线和候选片段；送审条件不足时保持基线，待审不显示为已通过。

满足门槛后，填写审核来源、审核者、具体理由与独立标签确认，明确授权原范围、次数和到期时间。查询只使用页面列出的开发组合；网络重试使用相同请求键，不重复扣次数。重启或恢复不会重置额度。

每次查询可选择反馈来源为人类或Agent协助意见。失败或仍不确定的质量反馈都会停止候选；通过反馈不会扩大额度或期限。用户可随时停止试用；已关闭、到期或护栏失败的试用不能复活或重置，需要新建旁路并重新核对。

来源版本、范围或默认基线变化时回到当前基线；候选伪造引用、丢失基线覆盖或超过上下文也停止。若**基线原始文件、SHA或引用也不可核验**，返回 `source_unavailable`、空证据及未知命中数/分母，不以未验证片段冒称可用，也不把它解释为零需求。

关联研究、偏好或知识资格改变时，按有界依赖审计停用，而不只看knowledge表中的active字样。遗忘闭包擦除试用评语、反馈和缓存结果；最少元数据只保留依赖ID，支持清理中断后的重试。原JD保留。

## 共用服务、接口与命令

`LocalRetrievalTrialService(store, repository)` 写入检查点数据库的 `retrieval_trials` 与 `retrieval_trial_events`，按业务库namespace隔离。不写全局策略表，不访问模型、外网或认证恢复。

| 接口 | 操作 |
| --- | --- |
| `GET /api/trials` | 安全评测包摘要与局部试用列表，不返回预留题/标签 |
| `POST /api/trials/shadows` | 指定包ID、岗位、开发词、次数和期限进行旁路 |
| `GET /api/trials/{id}` | 旁路片段、资格与审计记录 |
| `POST /api/trials/{id}/review` | 明确审核，默认待审 |
| `POST /api/trials/{id}/search` | 有限候选或基线检索，带请求键防重试扣次 |
| `POST /api/trials/{id}/feedback` | 明确反馈来源并记录质量反馈 |
| `POST /api/trials/{id}/rollback` | 停止候选，保持基线 |

HTTP不接受文件路径、任意SQL、题集、门槛或系统代码。只识别业务库同目录 `quality-trials/<32位小写十六进制ID>/` 中固定布局，及旧真实包只读复核入口。每包语料文件最多512MB，JSON文件最多16MB。

```powershell
# 新语料只冻结8张来源表，清除请求/访问上下文，不复制用户记忆和派生表。
uv run --locked python -m work_observer.quality freeze data/app.db data/quality-trials/<包ID>
# 必须实际由人类独立核对后才使用以下人类声明，不可由Agent代填为已人审。
uv run --locked python -m work_observer.quality lock data/quality-trials/<包ID> <本机标签文件> --label-origin human --reviewer <审核者> --independent-labels
uv run --locked python -m work_observer.quality evaluate data/quality-trials/<包ID> <候选别名文件> <开发输出文件>
uv run --locked python -m work_observer.quality evaluate data/quality-trials/<包ID> <候选别名文件> <验收输出文件> --phase holdout
uv run --locked python -m work_observer.quality.trials --db data/app.db list
uv run --locked python -m work_observer.quality.trials --db data/app.db shadow <包ID> --job <岗位ID> --term <开发词> --max-uses 5 --expires-hours 4
```

CLI `review/search/feedback/rollback` 与页面共用服务。非空基线别名需作为固定 `baseline-aliases.json` 保存在包内，并与当前默认基线及评测摘要一致；不能从模拟策略的绿勾偷渡为真实试用授权。

## 备份与恢复

完整备份包含两张试用表及新固定布局评测包。包内仅复制 `corpus.db`、`manifest.json`、`suite.json`、`candidate-<摘要>.json`、`holdout-attempt.json`、`holdout-result.json` 和可选 `baseline-aliases.json`；不复制任意文件、`.env`、脚本或可执行文件。最多100包、每包32个必要文件，逐文件SHA和内层冻结摘要、8来源表、无触发器/视图/虚拟表、访问上下文已清理均需核对。

等待人工标注的草稿同样可以备份，不阻断整个业务备份。最小草稿为 `corpus.db` 与 `manifest.json`；有suite时必须核对suite摘要和语料关联，有候选锁/预留attempt时也核对各自关联。缺少预留结果只记为草稿，完整结果记为已评测，均不等同已获试用人审。备份清单明确记录 `frozen_draft`、`labeled_draft`、`evaluation_draft` 或 `evaluated` 阶段，恢复保留阶段和文件原字节，不补造缺失文件、不将草稿升级就绪。坏checksum、不安全schema仍拒绝，不静默跳过。

恢复到新目录时**不修改冻结corpus字节或其原始路径字符串**，不能因此破坏已锁定语料摘要。实际试用引用改由恢复后的live库验证原文与SHA；恢复库中的原始资料路径正常重定位。额度、授权、期限与审计保留，恢复不自动执行检索。新库缺包、代码变化、到期或原始来源失效均安全回退/关闭。

旧 `quality-baseline-20261119-v1` 完整冻结包原样保留，未自动裁剪、升级或复制到新包备份布局。新source-only冻结不包含无关用户记忆；旧私有制品仍受其原保留边界约束，不能据新格式说明声称旧副本已被清理。恢复后旧包缺失时回到基线，不能宣称该旧包候选完整恢复。新固定布局中的旧格式副本会被备份验证拒绝，须重新锁定合规来源语料，不能改摘要冒充升级。

## 实际验证与尚未证明的部分

隔离测试使用明确合成资料和synthetic actor扮演人工动作：验证等待人审、人工有限试用、Agent/非独立标签拒绝、次数/到期/范围/查询/源漂移/配置与文件变化、伪造引用、质量反馈、默认全局检索不变、同请求幂等、重启与完整遗忘闭包。来源文件损坏时基线也关闭。偏好→研究→仍active的知识→后续研究→试用的链在偏好修订后停止，不能经旧知识绕过。

完整HTTP测试涵盖主页面与脚本、旁路→拒绝Agent授权→合成actor授权→有限查询与重试→失败反馈回退、Agent草案始终不足、CSRF/路径拒绝及关闭后重开。合成actor路径只证明机制，不是真实人类标注或市场改善。

备份测试实际移走测试原始raw与quality-trials目录后恢复：冻结corpus SHA逐字节不变，恢复live来源可验证，原候选次数1→2后再查询自动回基线，没有重置额度。即使更新外层文件hash，内部suite篡改仍拒绝恢复；任意路径和非固定文件不纳入。

真实旧资料只读备份到 `data/phase06-trial-verification/` 后复核7份真实既有正文：局部旁路可运行，但标签仍Agent草案、独立性未确认、holdout资格不足，状态 `insufficient`；实际查询使用baseline、候选使用0次、Agent授权尝试被拒绝，未尝试真实人类激活。外部调用0，正式库旧列逐值指纹保持一致。证据为该目录 `acceptance.public.json`。

目前没有真实独立人工验收样本和真实用户有限授权，因此没有真实accepted试用增益、长期退化率或语义支持率证明。有限词面试用也不等于任意研究方法自我改进；新增查询、来源组合或研究策略仍需另建冻结任务、独立标签和受限验证。
