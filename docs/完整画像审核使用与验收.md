# 完整画像审核使用与验收

2026-11-19。基础研究的判断与后续画像补充是不同审核对象：基础研究保存后，画像还会生成领域候选和面向招聘方的核实问题。审核基础`run_id`不能证明这些补充已经被核对。

## 可操作流程

工作台“完整画像核对”列出每份已存画像的判断、领域候选、核实问题数量，以及单独的人审状态和Agent反馈。打开后：

1. 对照完整原文核对六类判断，逐条判断引用语义和必备/加分/未明确性质。
2. 逐个核对领域候选是否有实际任务/责任依据、是否越过岗位归属范围，不能仅凭技术词确认执行平台或Harness。
3. 逐个核对问题是否在向招聘方澄清实际岗位缺口，而不是考察候选人或暗含未知事实。
4. 对引用语义、要求性质、画像覆盖、未知边界、反例、回答问题六维填写理由，保留重要遗漏。
5. 明确选择人类核对或Agent辅助反馈，保存待审、拒绝或人类批准。

Agent辅助不能批准。任何未评补充、未知评分、部分结果、缺少权威源运行、来源/偏好/方法失效均不能批准为完整画像。缺少类别是审核提示，不能机械等同于画像不完整：人类须对照全文，区分原文未披露与模型漏读，并在画像覆盖、未知边界和回答问题三维明确通过并说明理由。原文未披露的事实可以准确保留为未知，不代表岗位不好；审核者尚未核对而给出的未知评分仍不能批准。不能为了通过审核编造要求或责任。批准不会自动采纳领域知识或启用策略。

列表、核对包、匿名包和页面明确区分`synthetic/mixed/real_or_user_provided/unknown`。合成或混合资料中的“human”动作只验证机制，不构成真实人类业务验收；真实或用户提供的资料也不因此保证来源已独立核验或招聘状态实时有效。此展示元数据不写入原始画像，不改变artifact hash。

## 权威对象与缓存

审核绑定`JobAnalysis.id`和原始`row.result`的稳定SHA，包含判断、领域、核实问题、缺口及其他已存结果字段；不对当前渲染时注入的纠正或仅基础研究结果评分。只改补充问题或领域理由也会改变hash，旧审核单列为旧版本，不能静默套用。

匹配当前hash的人类拒绝会使该画像缓存失效；同输入重新分析生成新ID，旧画像及其审核保留。Agent拒绝只是反馈，不冒充人类拒绝，也不自动使有效缓存过期。画像审核不向基础`quality_reviews`写拒绝，不改基础运行或原始JD；基础研究中仍有支持的事实可独立保留和送审。

## API与独立盲审

| API | 行为 |
| --- | --- |
| `GET /api/profile-quality` | 当前画像列表、人审状态与Agent反馈 |
| `GET /api/profile-quality/analyses/{id}` | 动态读取完整画像、全文、引用和当前资格 |
| `GET /api/profile-quality/analyses/{id}?blind=1` | 动态匿名包，含完整判断/领域/问题与原文，不带既有评分、审核者、analysis ID或基础run ID |
| `GET /api/profile-quality/analyses/{id}/reviews` | 审核历史，明确旧hash状态 |
| `POST /api/profile-quality/analyses/{id}/reviews` | 逐项提交，繁忙时拒绝写入 |

提交包含`artifact_sha256/reviewer/reviewer_kind/decision/note/dimensions/claim_reviews/domain_reviews/question_reviews`。每个实际条目都要有对应索引、判定和非空理由；领域分别判断`support/scope`，问题分别判断`direction/relevance`。匿名包只在读取时产生，不另存一份画像结果；源数据或补充改变后重新生成当前包。

## 遗忘与边界

独立检查点表`profile_quality_reviews(namespace,id,analysis_id,record)`只保存审核及依赖ID，不复制完整画像。`ProfileQualityReviewService.invalidate(run_ids=(),profile_ids=(),memory_ids=())`在画像已被遗忘闭包删除后仍可按索引清除全部自由文本与关联通知；相同analysis的旧hash审核一并清除。最少记录保留源运行/记忆ID，进程中断后可重试。原JD、截图与独立备份按既有规则保留。

该机制不能自动证明人类评分真实或语义一定正确。有限语义复核、真实模型业务任务、人类验收和长期部署仍需分开报告；不能因提交审核接口或空字段检查通过就称画像成熟。

## 本阶段验证

12项隔离回归通过（9项服务、3项HTTP）：完整补充hash、动态匿名包不带旧评分、补充缺评或未知不能批准、Agent不能批准/不能冒充人审拒绝、画像人审拒绝不污染基础事实、新ID重算保留历史、部分/缺源/偏好变化、画像删除后审核擦除与幂等，以及同源写保护、页面/Schema和完整HTTP遗忘链。任务单一且仅披露任务的合成JD可在明确区分未披露与漏读、全部现有条目和六维人工通过后接受；同一画像的未知评分或补充生成失败的partial版本仍被拒绝。所有模型和人审动作都是明确合成机制材料，没有执行真实模型或将合成人审标记当成人类业务验收。

另将真实工作流两份画像的封存独立盲审意见登记为Agent辅助`reject/pending`，没有批准人类审核。绑定时实际发现旧`blind-bindings.result_sha256`只等于基础研究hash，不能声称此前已锁完整画像；逐项核对封存可见的判断、领域、问题、缺口、缺失维度及完整原文与当前画像一致后，本次首次建立完整artifact hash绑定。旧盲审包、bindings、独立review原件和基础运行均保持原样；详情在本机私有`data/phase07-real-workflow/20261119-1a0eeac1/profile-review-binding.private.json`，不复制完整result。
