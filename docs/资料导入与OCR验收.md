# CSV与截图资料补充

2026年11月19日。通过原有“补充岗位”窗口使用；所有资料仍需人工核对，不恢复暂停的招聘连接。

## CSV逐行预览

在“从文本 / JSON / CSV 文件读取”中选择UTF-8编码的CSV，支持BOM。每批最多20行、500KB；必须有`title`、`company`、`description`表头。其他原文字段沿用人工JSON格式，未知留空。需要维护同一份岗位时填写稳定的`external_id`。

[合成演示模板](../configs/manual-jd.example.csv)中的两条记录均明确为`data_kind=synthetic`，不是实际市场样本；请在独立演示资料库使用。

页面先逐行展示草稿与格式错误，尚未写入岗位。可以修改标题、公司、正文、资料编号及其他原文字段，勾选已核对的行后点击“导入已勾选并核对的行”。每行独立保存，失败行不影响已成功行；完成后会取消成功行的勾选。相同资料编号与相同正文复用原岗位和版本，不无限复制；标题或公司身份冲突会明确失败。

## 截图原图与待核对草稿

在“从截图整理草稿”中选择PNG、JPEG或WebP，最大5MB；明确是合成演示图时勾选相应性质。点击“上传到本机并预览原图”仅归档图片，不建立岗位。

如需模型辅助，必须明确勾选允许把这张图发送到已配置模型，再点击“抽取待核对草稿”。一次操作最多一个固定视觉请求，60秒超时，不联网搜索，不自动重试。缺少配置、服务拒绝、无视觉能力或响应不符合结构时，明确失败，仍可以对照原图人工填写。

成功抽取仅填入下方可编辑表单，尚未写入岗位。对照原图核对和修改，补足确实看得到的岗位名称、公司与正文；未知字段保持为空。抽取不会生成可靠发布时间，只保留图片明确出现的时间原文。最后勾选“我已对照原图核对并编辑以上内容”，再点击保存。

归档原图按文件指纹核对，岗位来源文档保存原图关联；之后可从岗位详情或来源核对再次打开。成功视觉抽取后人工核对的来源标记为“OCR人工核对”；未抽取或抽取失败后手工填写标记为“截图人工核对”。合成资料优先显示“合成演示资料（非真实招聘）”。原图缺失或指纹变化时拒绝继续读取或作为已核对资料保存。

原图、抽取结果及岗位数据库均留在本机的资料目录，不加入公开仓库。备份与恢复会包含原图及其指纹。
