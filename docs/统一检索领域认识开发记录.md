# 统一检索领域认识开发记录

2026-11-20，继续完成原文、有效知识和领域认识的统一检索主流程。

## 实际缺口

统一检索原来只返回岗位/归档原文与普通知识记忆，没有接入已保存的领域定义、工作关系和原判断。其派生知识范围还使用所有岗位ID，未随本次岗位筛选和历史截止重建范围，可能在只查上海样本时带入北京样本的认识。

## 本批行为

- 复用现有领域知识服务，将有效定义、关系、原判断口径、后续修正和来源回链接入统一检索，不建立另一套知识库。
- 各类派生认识与原文共用本次实际筛选和时间范围；项目内定义保持所属研究限制。已排除、撤回、依赖失效的记录沿原服务规则停止使用。
- 搜索可以在较大候选范围中定位原范围的认识，但明确标示其原岗位/归档范围，不将它扩成整个候选范围的结论。研究Agent原有的范围复用约束保持。
- 定义文字、包括条件和排除边界完整展示；放不下时整条省略并提供查看保存记录或来源研究的入口，不截短限定语。关系保留适用边界、原判断与要求性质；派生结果不作为可选择的原文证据，也不计为新岗位或独立来源。
- 已启用别名和同形部首匹配用于查找，保存文字、原文与引用保持原样。原文、记忆和新增领域结果共用既有检索内容上限。

检索页面可以从命中直接定位保存的定义/关系，或打开来源研究核对原文；未展开内容有明确入口与提示。页面没有新增审批步骤。

## 验证与边界

隔离资料验证了筛选一致性、较大范围中的原范围展示、项目归属、完整边界的长度处理、同形字查找、HTTP检索与地图保存复用；相关页面展示和语法检查通过。来源计数及样本分母仍只反映原资料，检索操作没有改写原研究或采纳状态。

没有新增真实模型调用、修改正式资料或安装/重启运行工作台。当前证明检索及复用入口已接通，不代表领域定义和迁移解释本身已获独立语义确认；完整GOAL继续进行。

## 研究复用时保留完整限定条件

随后检查实际研究工具时发现，其默认返回仍将定义截为1200字、纳入/排除各500字。这会使较长定义末尾的边界在传给研究模型时消失，页面完整展示本身不能解决这条使用路径。

研究工具现完整返回定义和纳入/排除条件，六个领域的这三类正文合计最多12000字符。放不下时整条省略，同时移除其关系线索、依赖和来源研究，明确返回被省略定义ID；原保存记录保持完整、有效。返回值同时标明匹配领域总数，超过六条而未展示的定义不再被误报成完整结果。工具说明随这项行为更新，沿用既有研究方法指纹，不新增审批或版本体系。

统一检索的普通保存知识现在使用与原文、领域定义相同的已启用别名。记忆召回的分词比较也使用既有同形部首规则；比较时折叠字形，保存文字与引用不改。关闭别名仍保持字面召回。

隔离研究替身验证了定义/纳入/排除末句实际进入模型工具上下文，并在重新读取原文后完成研究；多定义额度验证了整条保留或省略、关联关系和依赖一致、原记录不被改写。字形双向查找和别名开关覆盖保存知识召回。全部使用临时资料和工具替身，不调用真实模型，不作为真实领域语义质量证明。
