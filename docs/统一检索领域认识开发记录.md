# 统一检索领域认识开发记录

2026-11-20，继续完成原文、有效知识和领域认识的统一检索主流程。

## 实际缺口

统一检索原来只返回岗位/归档原文与普通知识记忆，没有接入已保存的领域定义、工作关系和原判断。其派生知识范围还使用所有岗位ID，未随本次岗位筛选和历史截止重建范围，可能在只查上海样本时带入北京样本的认识。

## 本批行为

- 复用现有领域知识服务，将有效定义、关系、原判断口径、后续修正和来源回链接入统一检索，不建立另一套知识库。
- 各类派生认识与原文共用本次实际筛选和时间范围；项目内定义保持所属研究限制。已排除、撤回、依赖失效的记录沿原服务规则停止使用。
- 搜索可以在较大候选范围中定位原范围的认识，但明确标示其原岗位/归档范围，不将它扩成整个候选范围的结论。研究Agent原有的范围复用约束保持。
- 定义文字、包括条件和排除边界完整展示；放不下时整条省略并提供查看保存记录或来源研究的入口，不截短限定语。关系保留适用边界、原判断与要求性质；派生结果不作为可选择的原文证据，也不计为新岗位或独立来源。
- 已启用别名和同形部首匹配用于查找，保存文字、原文与引用保持原样。原文、记忆和新增领域结果共用既有检索内容上限。

检索页面可以从命中直接定位保存的定义/关系，或打开来源研究核对原文；未展开内容有明确入口与提示。页面没有新增审批步骤。
