# 领域观察与个人目标影响

2026-11-19。本阶段提供可操作的观察面板冻结、两次观察比较、明确个人目标的证据影响和待补查衔接。不调用模型、不发起采集，不将两次静态观察写成市场趋势。

## 使用流程

在“领域观察与目标影响”中填写面板名称，选择已审核领域定义版本或全部岗位，可使用当前完整筛选范围或岗位页勾选范围。最多2000个范围岗位，超限要求缩小范围，不悄悄截取top-k。可指定最多10个统计词，并明确勾选是否解释已保存的个人条件。

点击冻结后保存来源快照、原始文件SHA、正文SHA、观察/入库时间、领域定义和关系版本、分类纠正、画像方法版本与相关记忆版本。保存的是本地观察面板，没有把本地冻结时间当作来源发布时间或新采集时间。未知发布时间仍为空，画像与关系缺失保持未知。

后续再次显式冻结，再选择两个面板生成幂等报告。同一对面板反复提交返回同一报告，不反复制造变化事实。报告分开呈现：

| 类别 | 展示与限制 |
| --- | --- |
| 原文与披露字段 | 比较同岗正文版本、标题/城市/薪资等披露字段；仅城市变化不算正文变化。正文补全与已取得正文内容变化分开。保留版本、差异和原文回链。 |
| 样本及范围 | 加入、离开和共同岗位；筛选/指定岗位/领域范围是否变化。离开面板不表示岗位关闭，加入不表示当日新招聘。 |
| 分析与分类口径 | 画像方法/版本、领域定义、关系审核、人工分类及字面统计词的变化。方法变化与来源变化分别解释。 |
| 完整分母统计 | 先计算完整明确符合条件且原文可核验的正文分母，再统计字面命中；条件或领域未知单列。没有分母时命中数为空，不写“0个需求”。 |
| 明确个人目标影响 | 只取有效且用户明确提供的全局/当前岗位偏好；结构化城市、薪资、用工形式作逐项字段比较，期望任务作字面证据命中或待核实。文本偏好只展示为待解释的明确偏好，不自动推导硬条件、履历、能力或适配分数。 |

目标修订后，新面板只使用当前有效值。历史报告保留当时口径，读取时显示所用记忆是否已变更。忘记相关记忆或上游研究时，清理关联面板、报告和待补查文本，旧记录无法被重新提交复生。为支持中断重试，失效最少元数据保留依赖ID与版本，不保留目标或评语正文。

报告可保存具体待核实问题进入收件箱，也可建立有明确岗位范围的研究项目及一个待调查步骤。保存不会执行模型；用户在项目中继续才开始。通知、项目来源键和步骤键保持幂等。项目最多20个岗位，更大面板需用户明确选取子集；不自行扩大或截取范围。

## 服务与接口

共用服务是 `DomainUpdateService(store, repository)`，记录存入独立检查点数据库的 `domain_update_captures` 与 `domain_update_reports`，均按业务库 namespace 隔离。检查点备份需包含这两张表；恢复时 namespace 迁移应与研究项目/审核表一并处理。

| 接口 | 操作 |
| --- | --- |
| `GET /api/updates` | 已冻结面板及报告列表 |
| `POST /api/updates/captures` | 显式冻结当前完整范围、定义和可选个人目标 |
| `POST /api/updates/compare` | 比较两个面板，返回同一对面板的幂等报告 |
| `GET /api/updates/reports/{id}` | 读取报告及当前记忆有效性提示 |
| `POST /api/updates/reports/{id}/followup` | 幂等保存待核实问题，返回问题与范围供项目衔接 |

接口不接受文件路径、任意SQL、模型权限或来源恢复操作。普通读取与冻结在后台线程执行，外部调用为零。遗忘共用 `invalidate(run_ids, memory_ids)`，它同时清理受影响更新通知，返回失效面板/报告ID；重复调用仍能沿ID元数据完成清理。

## 实际验收

隔离机制测试8项通过：完整分母/重复观察、原文与样本/筛选分离、领域版本变化、仅披露字段变化不冒充正文变化、明确个人条件与未知字段、遗忘及中断后重复清理、待补查到项目的重复提交不建重复步骤且不运行模型、HTTP路由拒绝任意文件/预算字段及执行繁忙状态。测试均为明确合成资料，不是时间趋势或真实研究质量证据。

另有1项完整工作台HTTP集成通过：实际主页面与JS入口、合成导入→两次冻结→完整分母报告→待补查→幂等项目/步骤；重复创建不生成重复项目，用户修订项目范围后用原来源键重试返回冲突而不恢复旧范围；无同源写凭证被拒绝；动态API合同含新入口；关闭应用后重新打开仍可读两面板、同一报告与项目。该集成没有调用模型。

真实资料演示只读备份正式库到 `data/domain-update-verification/` 后操作副本，正式库旧表旧列逐值指纹保持一致。真实静态面板连续冻结两次：

| 项目 | 实际结果 |
| --- | --- |
| 范围 / 有正文 / 缺正文 | 15 / 7 / 8 |
| Python字面命中 | 4/7 |
| RAG字面命中 | 1/7 |
| 领域分类 / 画像 | 15个分类未知 / 15个无画像，未解读为没有能力要求 |
| 原文 / 披露字段 / 样本增删 / 方法变化 | 均未检测到变化 |
| 趋势结论 | `insufficient_comparable_time_series`；重复观察不构成变化证据 |
| 个人目标 / 外部调用 | 本次未启用个人目标 / 0 |

证据为本机私有 `data/domain-update-verification/acceptance.public.json` 及该目录检查点数据库。没有新招聘请求、没有恢复暂停来源。真实资料尚无充分跨日可比任务序列、有效领域关系和画像积累，本阶段没有证明职业演化结论或对个人目标的长期影响；页面视觉操作与目标环境部署仍应分别验收。
