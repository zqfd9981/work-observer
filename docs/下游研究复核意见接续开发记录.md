# 下游研究复核意见接续开发记录

2026-11-20。仅源代码与隔离验证，无外部模型调用，未操作正在使用的工作台。

## 已复现问题

原判断被后续研究提出疑问后，更晚的研究可能重新保留原判断。已保存知识的召回已有这类提示，但项目下游研究的沿用提示只接受修订、撤回与未解决，直接忽略全部保留意见。因此从旧下游继续追问时，只能看到早期疑问，无法获知后续复核处理。

## 修复行为

- 保留原有判断下标及原话精确匹配，并沿用调用方对来源、范围、审核与遗忘的有效性过滤。
- 对下游研究之后出现的同一原判断意见，保留疑问，同时带入后续最近一次重新保留的意见。单纯保留、从未被质疑的原判断不会因此新增影响提示。
- 连续多次保留不挤掉前面的疑问；中间未展示意见计入省略数。若更晚再有新疑问，早先保留不被用来清除新疑问。
- 继续最多展示3项，附完整理由与逐项对照。界面明确标作“重新保留”，导出沿用相同内容。
- 不因意见较新就判定为真，不自动改写旧回答或知识采纳状态。后续研究仍需核对原文。

## 验证

先复现早期疑问之后的保留意见缺失。隔离存储测试覆盖关闭后重新打开项目、沿旧下游追问、两次意见进入下一轮模型上下文及其 `continued_from` 来源依赖、后续记录失效后排除该意见、原下游记录不变。所用模型是本地测试替身，只读取合成任务，不验证真实研究语义。

单元测试覆盖多次保留与再次质疑、原话不匹配、无关研究、间接下游和省略数。界面与导出回放验证两次意见可见、原研究链接保留与文本转义。本次功能修复不能证明原真实研究的保留/修订判断已经正确；既有真实失败和未完研究保持原记录。
