# G6 持续研究使用与验收

2026-11-18。此阶段属于[完整产品](完整产品验收清单.md)中的一部分，不能据此宣称完整产品完成。

## 实际能力

- 研究先确认固定SQL范围，自主拆解计划、读取原文、必要时公开搜索、比较已存详情历史，并返回六类判断、引用、信息缺口和固定程序复盘。
- 问题、计划、工具轨迹、结果自动保留于独立 `checkpoints.db`，不是新增岗位事实。服务重启后能查看历史；中断研究由用户点击继续，不自动花费模型额度。
- 继续沿用原调用和耗时预算、原候选及启动时正文版本。正在等待时取消也计为已尝试调用；发生崩溃时对未知等待时间保守计费到时间预算。偏好/纠正发生变化时要求按新记录重新研究，不悄悄继续使用已撤回记忆。
- 业务库中的偏好、人工纠正及研究知识有版本和状态。知识先留为候选，用户采纳前不会默认召回；采纳重新核对快照、原文区间与原始文件SHA。来源变化、文件不完整、范围不符、撤回和旧版本不默认召回。
- 公开搜索默认关闭，勾选允许后最多两次。搜索生成摘要与网页节选均标明其性质、网址、取得时间及未知发布时间，不伪装为招聘原文。完整网页归档属于随后扩展。
- 一个研究运行最多12次模型调用、300秒；默认10次/180秒，最多20候选、60条已读证据。费用未知时保持未知，记录供应商返回用量。跨进程锁避免同一业务库被CLI和页面同时执行模型研究。

## 使用

已有库先执行 `uv run --locked work-observer db-init` 增量升级。升级自动用SQLite backup API备份并校验升级前所有旧列行值；不删除或重建业务记录。页面仍通过 `uv run --locked work-observer serve` 启动，默认本机8765端口。

研究工作台新增历史、计划、进度、暂停/继续及复盘；知识与偏好页面可创建、修订、撤回和采纳。保存报告仍是显式操作，重启后重复保存同一运行返回原报告ID。CLI新增：

```powershell
uv run --locked work-observer research-runs
uv run --locked work-observer research-run <运行ID>
uv run --locked work-observer research-resume <中断运行ID>
uv run --locked work-observer memories
uv run --locked work-observer memory-add preference "明确偏好内容"
uv run --locked work-observer memory-add correction "明确纠正内容" --job-id <岗位ID>
uv run --locked work-observer memory-propose <运行ID> 0
uv run --locked work-observer memory-change <记忆ID> activate
uv run --locked work-observer memory-change <记忆ID> withdraw
uv run --locked work-observer compare-history <岗位ID>
```

## 明确限制

公开搜索摘要仍需正文核验；知识当前只接受本地JD引用。程序复盘校验引用存在与执行合同，不证明判断语义一定正确。当前少量样本无法证明趋势，状态不是实时招聘保证。BOSS仍因code37暂停；自动认证、多天无人采集仍未通过验收。完整产品的画像、评测、收件箱与部署在后续阶段继续交付。
