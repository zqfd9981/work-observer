# 持续调查建议接续开发记录

2026-11-20，继续推进问题驱动调查及日常研究主流程。

## 已复现的问题

后续调查建议原本将完成条件与所需证据拼在一起，截为1000字符。两个字段各允许600字符，因此有效提交也可能丢失后半部分证据要求。

安排建议与原调查执行共用异常处理。原回答已保存、步骤已进入待核对后，若用户同时保存其他追问，安排建议会因项目发生变化而失败；执行器随后将原运行标失败，并再次结束已经结束的步骤，触发STEP_NOT_RUNNING。使用隔离资料和模型替身复现了该路径，没有调用实际模型。

另外，建议因额度或轮数不足未安排时，原建议留在数据里但日常对话和导出缺少完整、可使用的说明。

## 本批行为

- 完成条件和所需证据分开保留，后续调查上下文分别取得完整内容；不截短、不更改原研究额度。
- 原回答保存完成后独立安排建议。安排失败只记录该建议的原因，不将已完成回答改成失败；独立的用户追问仍可继续执行。
- 安排前核对建议所属范围；原调查后研究范围或目标已经调整时，保留建议，不自动套用到新范围。
- 明确记录已安排、已有相同调查，以及因额度、轮数、范围变化或同时修改而未安排的原因。既有调查仍按原额度运行，不自动重跑失败研究。
- 研究对话与项目页显示建议的完整问题、完成条件、所需证据及当前安排状态。已经生成后续回答时可直接回查；未安排时可以只准备追问，不发起请求或增加额度。
- 当前认识保留可继续追问的未安排建议；已有安排的不重复列作待新建问题。单轮报告保留原建议，整项导出同时说明当前安排状态。

## 验证与事实边界

针对完整条件、项目同时修改、额度不足、范围调整和安排失败后继续独立步骤做了本地流程检查，并检查了相关队列领取、预留额度、对话展示和导出。使用的是临时资料与模型替身；工程行为通过不代表Agent提出的问题有足够研究价值，也不代表真实语义质量验收完成。

原三轮真实研究的状态、失败、预算和原始材料没有改写；未追加真实模型调用，未安装、重启或访问用户工作台。源码已改进，当前运行工作台仍需后续集中更新。完整GOAL保持进行中。
