# 研究内容相关性接续开发记录

2026-11-20，修复持续项目通过旧问题文字选择研究、却忽略已形成认识的问题。

## 已复现的缺口

在隔离项目中，先形成工作地图，再调查其中一条判断的责任边界，关闭并重开项目。新问题只询问原地图里的资格强度和规模适用范围，不指定追问对象，也不重复最初问题的措辞。既有路径只匹配旧问题文字，未带入原地图及后续修正；新增回归在查找原研究时实际失败。

这会让已形成的工作类型、任务/能力关系和迁移条件留在旧页面，而后续研究无法从这些认识继续调查。

## 当前行为

- 持续研究在原有同项目、资料范围和来源资格规则通过后，按旧问题、原判断、地图的工作内容/关系解释/边界、待核实点和资料缺口选择相关研究。没有扩大资料范围或跨项目自动引入其他研究。
- 判断排序同时参考相关关系、比较所连接的判断，优先携带两端原判断，保留原下标、完整文字和要求性质。版本号、字段名、类别标签和未形成判断的原文片段不用于这种研究内容匹配。
- 仍使用既有三轮选择与14000字符上下文限制，原有后续修正、来源审计、历史对照、缺失计数和原文重读要求继续有效。相关性只用于定位线索，不证明语义支持、不代表用户采纳或独立来源。
- 不再要求用户记住旧问题措辞或必须点中某条旧回答，明确追问与依赖步骤仍保留原有优先级。没有新增模型调用或审核步骤。

## 验证与边界

隔离回归覆盖明确追问和未明确追问两种重新打开项目的路径。后者实际将原地图、完整资格表述、两侧比较和后续修正传给工具替身，再读取两份原文，通过四次本地模拟调用完成回答；保存了研究关联，未改写旧回答。

相关性检查还覆盖只在地图边界/待核实点中出现的主题、比较双方的原下标与资格强度、同形部首文字，以及程序元数据不参与内容匹配。测试全部为临时合成资料和工具替身，不代表真实模型的语义判断质量。

相关回归同时覆盖范围调整、上游修正、遗忘、拒绝后的复核补查、普通项目/对话和历史来源复用。检查中三项旧断言在本轮改动前的HEAD实现也会失败，已通过内存载入该版本复现，未回退工作区文件：扩范围后的旧判断应只作历史对照；带岗位的复核研究已有历史读取能力后缀；复制回答工具应保持当前标准方法不变，而不应要求功能已变化后仍等于过去的固定指纹。对应断言按这些实际约束更新，保留了后续预算、拒绝隔离、原回答不变及工具不被修改的检查，失败路径复验通过。

没有新增真实模型调用、修改正式资料、原研究或运行工作台。完整研究Agent目标仍在推进。
