## 对全量岗位复查的判断

**当前 MCP 还不能直接承担“数据库中只有 Job ID，也能稳定批量复查状态”的任务。** 原因有三点：

1. 当前 MCP 要求 `security_id`；固定会话详情实现还依赖匹配的近期搜索上下文，包括 `lid`。缓存有效期为 24 小时，这不保证旧岗位数天后仍可直接访问。
2. 虽然底层详情有 `jobStatusDesc`、`invalidStatus`，当前连接器的详情归一化代码没有将它们返回给项目。需要适配后才能让业务流程使用，不能从 `ok=false` 推断关闭。
3. 已验证的 Job ID 网页入口是一个可继续研究的复查路径，但目前依赖登录浏览器。还没有验证自动读取、批量运行、限速、登录过期、风控及重启恢复，不能据此承诺零人工定时任务。

后续优先验证独立 HTTP 查询和已保存访问参数的跨日复用；网页入口仅作为已确认可定位岗位的辅助证据，不将逐条页面操作确定为定时任务主方案。还需补足未收藏关闭样例；取不到详情时应记录“状态未知／复查失败”，不直接改为关闭。`invalidStatus=true` 的实际含义尚无关闭 JSON 样例验证，不预设枚举映射。

### code 37 原因追查

同日继续核对原始响应、本机源码与上游一手说明，未追加 BOSS 请求，未清理暂停状态。

本次响应除了 code 37 和“您的环境存在异常.”，`zpData` 仅包含 `seed`、`name`、`ts` 三个字段，没有 `jobInfo`。它是访问环境／安全校验分支的响应，不是正常岗位详情，也没有明确的账号登录过期文案。这里仅记录字段名，不公开校验参数值。

上游 [code 37 分类修复](https://github.com/can4hou6joeng4/boss-agent-cli/pull/403) 明确纠正了“所有 37 都是令牌过期”的旧映射：只有明确的凭据过期文案才进入刷新分支，环境异常及含糊响应进入停止分支。这是连接器的分类约定，不冒充 BOSS 官方公布的错误码规格。

| 已核对项目 | 事实与判断边界 |
| --- | --- |
| 登录资料是否完全缺失 | 否：存在 `wt2`、`stoken`、UA，保存的 `stoken` 与同份 Cookie 一致。存在不等于服务器仍认可，无法离线判定账号登录已失效或仍有效 |
| 是否包含完整页面身份信息 | 本地加密资料没有 `token`、`zp_token` 两项页面身份头；源码仅在保存了它们时才为 HTTP 请求附加。缺失是事实，尚未证明补足后就成功 |
| 为什么可能漏存身份信息 | 定制登录流程在用户已加载的页面上才开始监听请求；若后续校验期间未出现带这些头的页面业务请求，采集结果可以为空，仍会保存 Cookie。它没有以 HTTP 详情成功作为登录保存的验收依据 |
| 为什么浏览器成功不能证明保存资料有效 | 固定浏览器从当前会话使用实时 Cookie，独立 HTTP 使用几小时前保存的副本；两条路径的认证状态并未被证明相同 |
| 详情请求还有什么差异 | HTTP 通用实现自动在查询参数中加入保存的 `__zp_stoken__`；固定浏览器实现对详情接口明确不加该查询参数。该差异经源码确认，是否造成此次错误仍需受控对照 |
| 是否确定代理出口不同 | HTTP 环境代理与 Windows 的 HTTPS 代理地址配置一致；Chrome 启动参数没有单独指定代理。没有检查实际出口 IP，不能声称已完全排除网络环境差异 |
| 是否确定请求过密 | 本次纯 HTTP 只发了一次请求，随后停止，无法将该诊断归因于其自身连续高频请求；此前网页流量没有完整记录，不能排除账号累计风险 |
| 是否是平台完全禁止独立 HTTP | 未证明。上游有纯 HTTP 成功及失败的历史观察，同时明确称其线上稳定性未证实，不能据历史样本承诺本账号可用 |

现阶段可确定的错误类别是“安全／访问环境校验未通过”；具体触发项尚不能唯一归因。优先待核查的是保存的安全令牌是否仍有效，以及登录保存是否完整。没有证据把本次 code 37 归因于岗位关闭或 `securityId/lid` 跨日失效。

进一步定位需要官方目标业务页恢复后，先验证账号会话，再以明确恢复的单次只读对照区分当前有效资料与历史副本。不能凭静态字段存在就宣布登录有效，也不能凭一次环境异常就自动重登、生成校验答案或换通道连续试错。上游对此的边界见 [平台风险说明](https://github.com/can4hou6joeng4/boss-agent-cli/blob/master/docs/platform-risk.md)。本轮只保留本地分析，未改动外部连接器安装。

**仍未解决：** 获取此次可用资料的前置步骤借助了已登录浏览器；还未证明不启动浏览器的认证冷启动、自动续期或多天稳定运行。约 32 小时前的另一组岗位参数没有查询，这次单请求授权已用完，不扩大请求范围。当前只能确认约 4.63 小时的参数复用成功，不能写成跨日或多日验收通过。
